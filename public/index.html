4. Choose where to save

Use a short local path. Paste a folder path from Explorer or Finder; the final folder is created if it does not exist. Files are saved unencrypted. New exports use archive/ for readable files and _work/ for resume and recovery. Keep both while exporting.

5. Choose how to run

Files download sequentially. Temporary rate limits trigger automatic waits and retries; repeated limits slow the pace. Keep this computer running and connected.
